# PrivacyClear

A comprehensive privacy-focused application with a modern tech stack combining Next.js frontend, FastAPI backend, and advanced AI/NLP capabilities.

## Project Structure

- **Frontend**: Next.js with TypeScript and TailwindCSS
- **Backend**: FastAPI with PostgreSQL, Redis, and Celery
- **AI/NLP**: RAG pipeline with fine-tuned LLM using Pinecone, PyTorch, and Hugging Face

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### AI/NLP
```bash
cd ai-nlp
pip install -r requirements.txt
python main.py
```
